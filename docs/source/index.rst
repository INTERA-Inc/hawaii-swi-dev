MODFLOW 6 SWI Package tests
===========================

Notebooks that build, run, and plot the tests of the MODFLOW 6 Seawater
Intrusion (SWI) Package. Each is ported from an autotest on the ``feat-swi``
branch of `christianlangevin/modflow6
<https://github.com/christianlangevin/modflow6/tree/feat-swi>`_ and is run with
the latest `SWI preview build
<https://github.com/jdhughes-dev/modflow6-feat-swi-preview>`_.
